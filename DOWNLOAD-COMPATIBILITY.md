# Download compatibility review, 19 November 2026

Static compatibility findings against actual V3.4 b10 installation, Workshop 0.1.32 candidate, Arsenal 1.2.1 and optional Guppy/Bdub candidates. These are not live-play guarantees. All extras remain uninstalled.

| Download | Finding | Workshop implications |
| --- | --- | --- |
| GNS Beautiful Bases 3.0, archive 3.7, metadata 2.0 | XML-only, native assets plus bundled resources; 16 new blocks/16 recipes; 31 shape appends. Applied ordered block/recipe/shape patches against installed native XML. Only two remove selectors miss already-absent church-bell Harvest/Destroy drops; all other selectors match. Uses supported Light/PoweredLight classes. | Suitable for an isolated playtest. Changes pickup/salvage behavior of many existing decorative props; verify native-container/owned-storage handling. New decorative outputs are not automatically assigned Construction practice. Stale ModInfo version alone is not treated as proof of incompatibility. Not installed. |
| Looted 3.4.9 | DLL advertises game 3.4. All 338 direct Assembly-CSharp/firstpass member references resolve against installed assemblies. Its native map attachment selector matches. Required Harmony/Unity/NGUI/InControl/LogLibrary references are available; options declaration and menu/UI definitions included. | Good candidate for map/cleared-POI tracking. Workshop HUD edits inventory panels; Looted changes map/menu, so no direct XML target replacement conflict found. Live map scaling, markers, restock state, options and save/reload still need checks. No claim every dynamically named Harmony patch resolves. Not installed. |
| Elisk's Zombie Pack 2.0.11 for 3.3-3.4 | DLL: 367 direct native member references resolve. Bundles GearsAPI; Gears settings UI is optional per supplied README. No entity-name collisions with inspected Guppy. | Compatible-looking optional challenge expansion, not just visual variety: Mole permanently digs natural ground, Hush affects audio/stealth, Charger damages bases/throws loot cars, Riot Cop has armour. Land claims do not prevent Mole ground digging. Combining spawn/AI/audio/physics hooks still needs live testing. Keep separate from the ordinary-zombie baseline until the player chooses this difficulty. Not installed. |

Original files and read-only review used, no DLL executed as a test. Metadata resolution cannot prove runtime Harmony targets, bundle loading, networking, UI behavior, stability or balance. No hypothetical problems are represented as confirmed bugs.
